# Verbum Bible — Legal and Support

Static public pages for the Verbum Bible App Store listing.

## Publish with GitHub Pages

In the repository settings, open **Pages** and select **Deploy from a branch**, branch `main`,
folder `/ (root)`. After GitHub finishes publishing, the pages are available at:

- `https://lennonlima100.github.io/verbum-bible-legal/privacy.html`
- `https://lennonlima100.github.io/verbum-bible-legal/terms.html`
- `https://lennonlima100.github.io/verbum-bible-legal/support.html`

Use the privacy URL in every App Store Connect localization that asks for it, and the support URL
for the support fields.
